A product registration automation script developed in Python using PyAutoGUI and Pandas to process product data from a CSV file and automate form submissions in a web-based system.

**Note:** The automation was developed for study and practice purposes.

## Features

• Automatically open the Firefox browser\
• Access a web-based registration system\
• Navigate through the login process\
• Import product data from a CSV file\
• Automatically fill product registration fields\
• Register product codes, brands, types, and categories\
• Enter product prices, costs, and observations\
• Process multiple products using a loop\
• Automate mouse and keyboard interactions.

## Run

Install the required dependencies:

```bash
pip install pyautogui pandas
```

Make sure the `csv-produtos.csv` file is available in the working directory.

Run the script:

```bash
python __main__.py
```
