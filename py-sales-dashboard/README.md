A simple sales management and data visualization application developed in Python using Streamlit, Pandas, and Plotly.

**Note:** The application interface is in **Portuguese (Brazil)**.

## Features

• Register sales with date, salesperson, product, quantity, and value\
• Display registered sales in a table\
• Store sales data in a CSV file\
• Calculate total revenue\
• Visualize sales by salesperson and product\
• Interactive bar chart\
• Interactive doughnut chart\
• Simple web-based dashboard.

## Run

```bash
streamlit run __main__.py
```
