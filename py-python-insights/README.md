A customer churn analysis project developed in Python to investigate cancellation patterns and identify factors associated with customer retention.

**Note:** The analysis was developed using a **Jupyter Notebook**.

## Features

• Import customer data from a CSV file\
• Explore a dataset containing customer information\
• Inspect dataset structure and data types\
• Remove unnecessary columns\
• Handle missing values\
• Calculate cancellation counts and percentages\
• Filter customer data\
• Generate histograms and visualizations\
• Explore factors associated with customer cancellations.

## Run

Open the notebook using **Jupyter Notebook** or **JupyterLab** and execute the cells sequentially.

## Technologies

• **Python**\
• **Pandas**\
• **Plotly**\
• **Jupyter Notebook**\
• **CSV**

## Concepts Practiced

• Data loading with **Pandas**\
• DataFrame inspection\
• Data cleaning\
• Missing value handling\
• Column selection and removal\
• Data filtering\
• Frequency analysis\
• Percentage calculations\
• Histograms and data visualization\
• Exploratory Data Analysis (**EDA**).

## Purpose

Developed as a data analysis exercise to practice importing, cleaning, exploring, and visualizing customer data using Python, with a focus on understanding cancellation patterns and supporting data-driven decisions.
