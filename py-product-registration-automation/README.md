A simple AI chatbot developed in Python using Streamlit and the Google Gemini API through the OpenAI-compatible interface.

**Note:** The application interface is in **Portuguese (Brazil)**.

## Features

• Interactive chat interface\
• Send messages to an AI model\
• Display AI-generated responses\
• Maintain conversation history\
• Store messages using Streamlit session state\
• Display user and assistant messages separately\
• Simple web-based interface.

## Run

Install the required dependencies:

```bash
pip install streamlit openai
```

Run the application:

```bash
streamlit run __main__.py
```

## Technologies

• **Python**\
• **Streamlit**\
• **OpenAI Python Library**\
• **Google Gemini API**

• API integration\

## Security

API keys should be stored securely using environment variables or Streamlit secrets and should never be committed to GitHub.

## Purpose

Developed as a programming exercise to practice API integration, conversation state management, and interactive application development using Python, Streamlit, and an AI model.
